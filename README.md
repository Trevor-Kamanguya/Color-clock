#Welcome Color-clock

 - A colorful digital clock built using React and Vite.
#Description

- Displays the current time in real-time
- Updates automatically every second
##Features
- Live updating digital clock
## Technologies Used

- React
- Vite
- JavaScript
- CSS
- date-fns
  ## How to Use the Project

1. Open the application in your browser using the local development link provided by Vite.

2. The digital clock will automatically display:
   - The current time
   - The current date
